# Hardine Blog

The frontend repository of the Hardine Blog app

- Demo: [Live](https://hardine-blog.netlify.app)
- Backend for [Hardine Blog](https://github.com/d-hardine/hardine-blog-back)

## Features
- Secure authentication with with JWT strategy.
- Client-side routing with React Router.
- Fetches posts and comments from an Express API.
- Search and category filtering.
- Comments on posts.
- Dark or Light mode.


## Built with
- Vite + React
- Bootstrap
- React router v6
- Axios
